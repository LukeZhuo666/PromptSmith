# 提示匠（PromptSmith）

提示匠是一款本地 Prompt 构建工作台。填写任务、角色、语气和输出格式，即可整理出可复制、可修改、可保存的完整指令。

## 开始使用

打开 [提示匠](https://lukezhuo666.github.io/PromptSmith/)，选择任务类型，描述目标并补充限制条件，点击“生成 Prompt”。复制结果到常用 AI 工具即可使用。

## 功能

- 覆盖写作、学习、编程、策划与研究任务
- 组合角色、任务、语气、输出格式和约束
- 提供结构完整度提示
- 收藏 Prompt、查看最近使用记录、导出文本
- 在浏览器本地完成，无 API Key、无需账号

生成器负责整理指令，不会在页面中调用模型或上传输入内容。
